# kubsei-users-lib-java

OpenAPI contract of kubsei-users (`src/main/resources/openapi.yaml`, paths/schemas/responses under `openapi/`)
plus the Spring interfaces and models generated from it (`com.kubsei.users.api`).

OpenAPI 3.0.3: openapi-generator does not resolve multi-file specs correctly in 3.1 mode, and cannot read 3.2.

Published to GitHub Packages on every push to `main` (`com.kubsei:kubsei-users-lib`).
